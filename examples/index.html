    05 — Integration

    Two calls, one lifecycle.

    Install with npm install zikra-slider-pro, then call it as a factory or with new. Both return the same instance, with update(), on() and destroy() ready.

    VanillaReactNext.js App RouterVue 3

    Vanilla JS

    Script tag global or ES module import.

    const slider = zikraslider('#hero', {
  type: 'slide',
  loop: true,
  slidesPerView: 1,
  features: { autoplay: { enabled: true } },
  animation: { library: 'auto', effect: 'zoom' },
  on: {
    beforeChange(e) { // return false to cancel }
  }
});

slider.on('afterChange', ({ index }) => console.log(index));
slider.goTo(2);
slider.destroy(); // restores the original DOM

    Framework wrappers

    See examples/react, examples/nextjs and examples/vue for ready-to-copy components.

    // React / Next.js ('use client')
useEffect(() => {
  let slider;
  import('zikra-slider-pro').then(({ default: zs }) => {
    slider = zs(ref.current, options);
  });
  return () => slider?.destroy();
}, []);

// Vue 3
onMounted(() => { instance = zikraslider(el.value, props.options); });
onBeforeUnmount(() => instance?.destroy());
